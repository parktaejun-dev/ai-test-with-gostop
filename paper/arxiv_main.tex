\begin{abstract}
We study a blocked factorial question for four-player Go-Stop: in fixed-policy language-model play, does more variance come from model identity or from explicit prompt strategy? The repository implements a reproducible \texttt{4-model $\times$ 4-strategy} OpenRouter evaluation harness with repeated-layout blocking, session-level export, and effect-size-based reporting. The main report decomposes mean session profit into model, strategy, and interaction terms, and keeps CVaR$_{0.05}$ and ruin probability as secondary robustness metrics. Unlike the earlier heuristic-only benchmark, the main paper bundle is organized around \texttt{rq\_model\_vs\_strategy}. Because live OpenRouter credentials are not checked into the repository, the checked-in main bundle is a deterministic factorial smoke bundle used to validate the full paper, dashboard, and artifact path end to end. In that bundle, the model term dominates mean-profit variance (partial $\eta^2 = 1.00$), while strategy and interaction are zero. We therefore present the repository as an artifact-complete blocked factorial evaluation system whose checked-in bundle verifies the reporting contract and whose live empirical run can be reproduced by executing the pinned study definition.
\end{abstract}

\section{Introduction}
This paper is about evaluation, not training. The repository measures fixed Go-Stop policies under replayable conditions and asks a factorial question: when large language models play Go-Stop under frozen prompting regimes, how much performance variation is attributable to model identity and how much to prompt strategy?

That question matters because prompt-based policy induction is cheap while model substitution is expensive. If prompt strategy dominates, smaller or cheaper models can remain competitive once they are given stronger behavioral scaffolding. If model identity dominates, prompt design has limited leverage in this domain. If the interaction is large, neither factor can be discussed in isolation.

The repository therefore moves beyond a heuristic sanity-check benchmark and centers a blocked factorial LLM study. The earlier four-heuristic benchmark remains in the repository as appendix calibration. It establishes that the environment is deterministic, repeated layouts reveal seat effects, and the harness detects stable policy differences before the factorial LLM study is run.

The paper asks three questions.
\begin{itemize}
    \item \textbf{RQ1}: Which factor explains more variance in mean session profit, model identity or prompt strategy?
    \item \textbf{RQ2}: Are model and strategy differences robust on tail risk and ruin?
    \item \textbf{RQ3}: Is there a meaningful model-by-strategy interaction?
\end{itemize}

The repository contribution is threefold. First, it defines a reproducible blocked factorial evaluation harness for four-player Go-Stop. Second, it freezes both the model panel and the prompt strategy set so that factorial comparisons are implementation-stable and artifact-complete. Third, it ships a paper bundle, dashboard path, and archive viewer that consume the factorial report structure rather than the older baseline-only report shape.

\section{Related Work}
The closest systems reference is OpenSpiel, which treats games as controlled experimental environments rather than as ad hoc demos \citep{lanctot2019openspiel, openspiel_repo}. Our setting differs in two ways: Go-Stop has strong seat-order nuisance variation, and the primary competitors are not trained RL agents but frozen heuristic or prompted LLM policies.

The evaluation question also overlaps with zero-shot and ad hoc coordination work, where fixed behavioral diversity and policy mismatch are part of the experimental object \citep{hu2020otherplay, anyplay2022, behavioral2023, fewshot2023}. Risk-sensitive analysis matters because Go-Stop rewards are heavy-tailed at the session level; we therefore keep CVaR and ruin probability alongside mean profit \citep{riskbayes2022, rsrlcvar2023}. For uncertainty summaries we rely on bootstrap-style reporting and exact finite-sample interval conventions already standard in the repository tooling \citep{efron1994introduction, good2005permutation, wilson1927probable}.

\section{Methods}
\subsection{Environment Scope}
The harness evaluates fixed policies only. Learning, online adaptation, and log-based policy updates are disallowed. The benchmark uses a four-player start, eight floor cards, seven cards per player, and a three-active-player main game after participation decisions. Two jokers are included. \texttt{ChooseMatch} is modeled as an explicit action when multiple same-month floor cards exist. Showdown proposals are limited to one per player per hand, and showdown evaluation is defined as the difference between actual settlement and a no-showdown counterfactual at proposal time.

\subsection{Blocked Factorial Design}
The main study is a blocked factorial experiment over a fixed \texttt{4-model $\times$ 4-strategy} grid. Factor A is model identity, implemented as a pinned four-model OpenRouter panel recorded in repo-tracked configuration and manifest metadata. Factor B is prompt strategy, implemented as four frozen English prompt files: \texttt{Balanced}, \texttt{Analytic}, \texttt{Conservative}, and \texttt{Aggressive}.

For each strategy, we evaluate the same four models under exhaustive seat-order permutations. We enumerate all $4! = 24$ seat layouts, repeat each layout across deterministic seeds, and keep the paper defaults of 300 hands, initial bankroll 1000, and stake per point 1. Each repeated-layout condition becomes a nuisance block identified by
\[
\texttt{factorial\_block\_id} = \texttt{base\_seed} \times \texttt{layout} \times \texttt{layout\_repeat}.
\]
Because the same block is replayed under each prompt strategy, model and strategy effects can be separated while holding the initial-condition block fixed.

\subsection{Estimands and Exports}
The primary estimand is mean session profit. Let $P_{m,s,b}$ denote terminal profit for model $m$ under strategy $s$ in block $b$. The factorial report decomposes the variance of $P_{m,s,b}$ across the \texttt{model}, \texttt{strategy}, and \texttt{model $\times$ strategy} terms. Secondary metrics remain empirical CVaR$_{0.05}$ and ruin probability.

The execution path \texttt{scripts/run\_openrouter\_factorial\_study.py} exports the same artifact family as the earlier baseline scripts:\texttt{report.json}, \texttt{manifest.json}, \texttt{agent\_performance\_table.csv}, \texttt{session\_observations.csv}, \texttt{session\_logs.jsonl}, and \texttt{cross\_play\_results.json}. The key addition is \texttt{rq\_model\_vs\_strategy} inside \texttt{report.json}. It records effect decomposition, dominant-effect comparison, cell means for the interaction plot, and model/strategy-marginal secondary metrics.

\section{Checked-In Main Bundle}
The repository does not contain live OpenRouter credentials. For that reason, the checked-in main bundle is a deterministic factorial smoke bundle published from \texttt{results/factorial\_smoke}. This bundle is not the intended final empirical submission run. Instead, it verifies that the repository now supports an end-to-end factorial artifact path: execution result, paper figures, paper tables, dashboard rendering, archive viewer rendering, and appendix separation.

The checked-in smoke bundle has the following configuration.
\begin{itemize}
    \item Model panel: \texttt{google/gemma-3-27b-it:free}, \texttt{meta-llama/llama-3.1-8b-instruct:free}, \texttt{mistralai/mistral-7b-instruct:free}, \texttt{qwen/qwen-2.5-7b-instruct:free}
    \item Strategy panel: \texttt{Balanced}, \texttt{Analytic}, \texttt{Conservative}, \texttt{Aggressive}
    \item Base seeds: \texttt{7}
    \item Session horizon: \texttt{2} hands
    \item Layout repetitions: \texttt{1}
    \item Complete factorial blocks: \texttt{1}
    \item Session observations: \texttt{16}
\end{itemize}

\section{Results}
\subsection{RQ1: Main-effect dominance}
The checked-in bundle answers RQ1 mechanically and unambiguously. Figure~\ref{fig:interaction} shows flat strategy lines: every strategy induces the same cell means for every model. Table~\ref{tab:main-effects} and Figure~\ref{fig:effects} therefore place all explained mean-profit variance on the model term. The model main effect has partial $\eta^2 = 1.00$, while both the strategy main effect and the interaction term are $0.00$.

In the same bundle, model-marginal mean profits are $120.0$, $-20.0$, $-40.0$, and $-60.0$ for Gemma-3-27B, Llama-3.1-8B, Mistral-7B, and Qwen-2.5-7B respectively. The dominant main effect is therefore \emph{model identity}. Under the checked-in smoke configuration, prompt strategy contributes no additional variance.

\subsection{RQ2: Tail risk and ruin}
Figure~\ref{fig:risk} summarizes the secondary metrics. The model-marginal CVaR$_{0.05}$ ordering matches the mean-profit ordering: Gemma-3-27B is best at $120.0$, followed by Llama-3.1-8B at $-20.0$, Mistral-7B at $-40.0$, and Qwen-2.5-7B at $-60.0$. Strategy-marginal mean profit is $0.0$ for all four prompt strategies, and strategy-marginal ruin probability is $0.0$ for all four prompt strategies. Model-marginal ruin probability is also $0.0$ across the board in this smoke configuration.

These values show that the checked-in bundle is internally consistent: the same factor that dominates mean-profit variance also dominates the risk summaries. But because ruin never occurs and the bundle contains a single complete block, this should be read as a contract-verification result rather than a substantive risk conclusion about real LLM play.

\subsection{RQ3: Interaction}
The model-by-strategy interaction term is $0.00$ in partial $\eta^2$ and $0.0$ in sum of squares. In the checked-in bundle there is therefore no evidence that any model benefits disproportionately from any prompt strategy. Again, this is a statement about the smoke bundle shipped with the repository, not a claim that real OpenRouter runs will have negligible interaction.

\section{Discussion}
The important repository change is not that the smoke bundle happens to favor the model term. The important change is that the factorial question can now be asked and answered with a self-consistent artifact path. Before this reframe, the repository could run baseline heuristics and some OpenRouter comparisons, but the paper bundle, dashboard, archive viewer, and execution UI were all still tied to the old baseline report shape. The current version removes that mismatch.

This matters for two reasons. First, the factorial result path is now explicit: \texttt{session\_observations.csv} carries \texttt{model\_id}, \texttt{strategy\_id}, \texttt{strategy\_label}, \texttt{prompt\_sha256}, and \texttt{factorial\_block\_id}. Second, the same bundle can now be read by the main dashboard, the archive viewer, and the manuscript asset tree without silently falling back to the appendix-only baseline contract.

\section{Limitations}
The checked-in main bundle is intentionally limited.
\begin{itemize}
    \item It is a smoke bundle, not the intended final empirical run.
    \item It contains a single complete factorial block and a two-hand horizon, so it is not statistically adequate for real model-vs-strategy claims.
    \item Live OpenRouter execution still requires external credentials and model availability outside the repository.
\end{itemize}

Accordingly, the manuscript should be read as an artifact-complete paper package plus a verified factorial report path. The substantive empirical submission still requires a pinned live factorial run to replace the smoke bundle under the same bundle-publishing path.

\section{Conclusion}
The repository now supports the question it set out to ask: whether model identity or prompt strategy is the larger driver of Go-Stop performance variation. In the checked-in factorial smoke bundle, model identity dominates and both strategy and interaction vanish. More importantly, the repository now ships an end-to-end paper path that is aligned with that question: factorial execution, factorial statistics, factorial figures, factorial dashboard rendering, and appendix separation all consume the same report contract.
